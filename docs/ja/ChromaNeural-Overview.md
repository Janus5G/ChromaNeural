**rc.2 ドキュメントの状態：** この候補は一般公開されていません。ローカライズと拡張可能な i18n はローカル検証に合格しましたが、rc.2 のネイティブビルド／パッケージ受け入れは未完了です。以下のインストール、プラットフォーム、LAN/WAN、推論、実稼働サービスの証拠は、明示的に rc.2 と記したもの以外は過去の rc.1 の証拠です。rc.1 のダウンロードには rc.2 のローカライズは含まれません。

### ローカルの知能。明示的に承認する協働。

ChromaNeural はローカル AI 作業、永続的な作業キュー、承認済みピア間の通信を結び付けます。処理する入力と共有可能な貢献を選ぶのは利用者です。モデルが生成しただけでは、回答が正しい、または検証済みとはなりません。

この版で対応する協働プロファイルはコード提案です。任意のリモート作業を自動受諾・実行する汎用市場ではありません。デスクトップには、あらゆる種類の問題や研究を投入する汎用ボタンはまだありません。

### rc.2 の言語対応

単一クライアントに en、da、de、fr、ja、zh-CN、hi-IN を含みます。既定とフォールバックは英語です。サイドバーでアプリの表示を切り替え、次回起動用に保存します。拡張可能な登録簿により、別クライアントや GUI ロジックの複製なしで将来のカタログを追加できます。保存と起動時上書きは利用ガイドを参照してください。

- 既存の高度な CLI による、明示承認とタスク対応付けを伴うピア協働。

## 入力から結果まで

一般的なリソース共有は無効のままです。インストールや接続確認成功だけでは、ネットワーク参加承認、作業割当、ChromaPoints 付与は行われません。

### 1. 入力と許可

既存ジョブは入力元、指示、選択したプロバイダー／モデルを特定します。ローカル AI 処理とネットワーク利用はそれぞれ承認が必要です。フォルダーを開くことは共有許可ではありません。

### 2. キューと処理

既存 SQLite キューはジョブの識別と状態を維持します。リースでワーカー用に作業を確保します。制御された一時停止、キャンセル、停止、再起動は、記載された Windows プロファイル内で検証済みです。並行する別のジョブ DB は作りません。

### 3. 任意のピア協働

質問と回答は元タスクとの対応を維持します。ChromaSpeechAI は承認済みピアの識別情報と TLS を使用します。受信内容は受信箱に保存し、不活性なデータとして扱います。コード実行許可ではありません。ソース開示には明示的同意が必要です。

### 4. 完全性とレビュー

既存フローが提供する範囲で、結果は識別情報、ハッシュ、由来を持ちます。ローカル生成とピア生成の貢献は区別できます。SHA-256 一致は同一バイトを示すだけで、技術的品質を判定しません。既存の権威ある検証工程が受理するまで結果は未検証です。

### 5. 任意の公開

全体共有には、検証、同意、役割、バックエンド受理を伴う既存公開フローを使います。私的ファイルが自動的に Shared Network Knowledge になることはありません。公開ソフトウェアはローカル検証済みですが、本番公開サービスの稼働をこの版が証明するものではありません。

任意の全体共有に先立ち、依頼者が権威ある検証済み結果を私的に直接取得する機能は延期されています。まだ未検証のローカル結果を読むこととは異なります。

## プライバシーと信頼

### 三つの領域

**利用者のコンピューター：** 作業ファイル、設定、キュー、結果、ログ。ローカル AI は明示選択された入力をローカル処理します。アプリは保存データを自動暗号化しません。

**ブラウザー：** 既存 Web アプリが Internet Identity を使用します。実際に認証された呼出元によって所有者アクセスを判断します。コピーした接続メタデータはログインセッションではありません。

**承認済みピアと共有結果：** 関連する承認が送信内容を制限します。接続は IP アドレスやピア識別情報を明らかにし得ます。匿名性を約束しません。

外部サーバーでプロンプトを処理するサービスでは、入力がコンピューターの外に出ます。ChromaNeural のローカルプロバイダーは選択入力をその場で処理できます。ただしピア協働やブラウザー保存はデータ境界を越えます。違いは明示的な管理と分離であり、ネットワーク利用が一切情報を共有しないという約束ではありません。

### 検証済みの範囲

Windows クライアントとクリーンインストールは自動確認と人による GUI 受け入れ済みです。Windows、Linux amd64、macOS Intel はネイティブビルド／パッケージ確認済みです。実機2台 LAN、携帯回線から自宅への直接 WAN、実際のローカル推論の証拠があります。合成バックエンド状態や識別情報の試験は、実稼働 Internet Identity 試験ではありません。

### 未検証の範囲

実稼働 Internet Identity のエンドツーエンド、参加承認、移行。macOS の手動 GUI と Linux DEB の完全なインストール／削除ライフサイクルも受け入れ対象外です。ブラウザー所有者権限によるネイティブ私的ファイル転送は未実装です。特殊ハードウェア性能の物理検証もありません。

パッケージは未署名、macOS は未公証です。この先行版の制限内で Windows、Linux、macOS が公式プラットフォームです。

Android と iOS の公式対応は後日に延期されています。

詳しくは利用、プライバシーと保存、インストール、検証済み機能の各ガイドを参照してください。

MCP は rc.2 後に別途判断・承認する機能であり、ここでは未実装です。この文書は本番環境や Internet Identity の新たな変更を意味しません。
