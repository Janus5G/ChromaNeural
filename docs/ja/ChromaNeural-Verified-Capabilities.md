## 通信と作業フロー

### Windows 実機2台の LAN

双方向と質問／回答の往復を検証。TLS ピア識別、バイト一致、SHA-256、永続 SQLite 受信箱、再起動／再試行、重複保護、未知ピア拒否、受信内容不活性、制御終了を確認しました。

### Internet と NAT を通る直接 WAN

別の携帯回線のノードから自宅へ直接 TCP 接続しました。既存 ChromaSpeechAI は TLS 1.3、ALPN chromaspeech-prsm-v1、承認済みピア認証、100,000バイトで合格。バイトと SHA-256 は一致しました。再起動／再試行で既受信メッセージへの新規断片はゼロ。未知ピアは保存前に拒否され、受信箱は永続しました。

逆向きに独立開始する WAN は環境制約で未検証です。オーバーレイを代替と数えず、一時ルーター規則は試験後削除しました。

### バックグラウンド、リソース、対応付け

既存キューはクライアントの背景ライフサイクルに接続されています。Windows でリース、再試行、一時停止、停止、取消、再起動を対象確認しました。CPU スケジューリング、推論スレッド、コミットメモリーを制御しますが、物理 RAM 全体は保証しません。

タスク／ピア対応は実ローカル Windows TLS と SQLite で検証し、この試験の AI／バックエンドはモックでした。ローカルノード準備と認可接続は Windows SDK とローカル PocketIC 上の既存 WASM を使用し、実稼働参加承認ではありません。

### プライバシー、レビュー、公開

私的エンドポイント保護、所有者分離、キャッシュ／セッション消去、取得完全性はローカル検証済み。全体監査は既存管理者役割に限定し、私的記録内容への新権限は与えません。公開試験は検証、同意、役割、バックエンド受理を維持します。本番への新配備を証明しません。

## 修正と残る制約

### 実際に修正した欠陥

- Windows クリーン配布で欠けた SDK を、既存固定 @icp-sdk/core 5.4.0 と10実行依存物のビルド時梱包で修正。依存物更新や利用者の npm 導入はありません。
- タスク／ピアメッセージの欠けた関係を既存 ID、キュー、受信箱で接続。
- 私的エンドポイントと監査メタデータを、Internet Identity、所有者モデル、Candid、安定スキーマを変えずローカル修正。
- Windows 梱包の PowerShell モジュール発見と短／長一時パスを修正。過去の CI 失敗は保存。

BigInt エクスポートは互換性修正で、全環境で再現するランタイム障害ではありません。関係するバイトと契約が不変なら以前の PASS を再利用します。この表示更新は新機能試験キャンペーンではありません。

### 未検証または未提供

- 実稼働 Internet Identity エンドツーエンド、参加承認、移行。
- macOS 手動 GUI、Linux DEB 全導入／削除。
- 独立携帯試験環境での逆 WAN 開始。
- ブラウザー所有者権限のネイティブ私的ファイルと、全体共有前の私的結果直接取得。
- 制御付き Ollama/Linux/macOS/GPU 貢献。一般リソース共有は無効。
- 未署名パッケージ、未公証 macOS。アイコン制約は別文書。

Android と iOS の公式対応は延期です。

### ハードウェアと再現性

これはソフトウェアです。実 LAN/WAN と推論の証拠は試験した機械・接続に適用されます。シミュレーション、ローカルバックエンド、ハードウェアモデルは光学／GPU／特殊ハードウェアの物理性能を立証しません。

ネイティブ手順はクリーン checkout、固定 Actions／依存物、npm lock、ハッシュ確認済み実行資源を使用します。ランナー OS や実行メタデータがパッケージハッシュを変え得るので、全ビルド環境でバイナリ同一とは主張しません。VERIFICATION.md、NATIVE_BUILD_EVIDENCE.json が受け入れビルドを示し、取得ハッシュは docs/DOWNLOADS.md と SHA256SUMS.txt にあります。

MCP は rc.2 後に別途判断・承認する機能であり、ここでは未実装です。この文書は本番環境や Internet Identity の新たな変更を意味しません。
