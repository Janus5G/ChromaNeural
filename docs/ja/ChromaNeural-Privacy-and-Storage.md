## 三つのデータ境界

**ローカルクライアント：** ファイル、ローカルジョブ、設定、ログはコンピューター内にあります。作業領域と操作は利用者が選び、フォルダー選択だけで自動アップロードしません。

**ブラウザーと Internet Identity：** 私的 Web アクセスには既存アプリと実際に認証された呼出元を使用します。JSON の Principal は識別子であり、所有者権限の証明ではありません。ノードは人のブラウザーセッションを借用してはいけません。

**ピアと共有知識：** 別途承認した内容を承認済みピアへ送信できます。全体公開には固有の検証、同意、役割、バックエンド条件があります。私的データが自動的に Shared Network Knowledge になることはありません。

この分離は Internet Identity、Web 保存モデル、既存所有権を変更しません。保存時暗号化やネットワーク匿名性も意味しません。

### 集中型プロンプト処理との比較

中央 AI サービスが外部サーバーで処理すると、入力はコンピューターの外に出ます。ChromaNeural のローカル推論は選択入力を手元で処理できます。ネットワーク協働を選べば承認内容は外に送られます。Web アプリの私的保存は既存の所有者モデルで管理します。

他の AI がすべてプライバシーを欠くとも、ローカル保存だけで十分とも主張しません。OS、バックアップ、選択プロバイダー、承認内容も重要です。

### 暗黙の権限移譲はしない

API プロファイルには公開接続項目と Principal が含まれ得ますが、ログイントークンではありません。ノードには指定ローカルパスの別 ID があります。登録だけで参加承認されず、リソース設定で私的オブジェクトへのアクセスを得ることもありません。

## データの所在

### 既定の状態ディレクトリ

Windows：
```
%LOCALAPPDATA%\ChromaNeural\client
```

Linux と macOS：
```
${XDG_STATE_HOME:-$HOME/.local/state}/chroma-neural/client
```

macOS も Linux と同じ XDG／フォールバック規則であり、Library/Application Support を自動使用しません。明示した --state-dir が優先し、なければ CHROMA_STATE_DIR で別の場所を選べます。同じプロファイルを継続するには次回も同じ状態場所を使います。

### 状態ファイル

- **preferences.json：** テーマ、参加、CPU／スレッド／メモリー、アイドル／バッテリー設定、選択ノード設定パス。II セッションは含みません。
- **ui-language.json (rc.2)：** バージョン 1 と登録ロケール識別子だけを、GUI の明示選択時に同じ状態ディレクトリへ保存します。II セッションなし、preferences.json の変更なし。欠落・不正・過大・未対応なら破壊的書換えなしで英語へ。後の明示保存は不正原本を保全し、保存失敗時は現在の言語を維持します。--language 上書きは保存しません。
- **api-connection-v1.json：** 保存した API プロファイル。Principal は個人を特定し得るので、公開メタデータは匿名データとは限りません。
- **work-queue.db：** 既存 SQLite キューと関連公開状態。ソース、指示、結果、参照を含み得ます。利用中は -wal と -shm が作られることがあります。
- **balance-cache.json：** 以前取得した会計状態。キャッシュは権威あるポイント付与を生みません。
- **client.log：** 1ファイル最大 1 MiB、バックアップ3個のローテーションログ。トレースにはローカルパスが含まれ得ます。

不正な設定／プロファイルも読み取り時は保全します。後の明示保存で日付付きバックアップを残せます。診断時に自動削除しないでください。

### その他の明示選択場所

作業ファイルは選択領域内です。ノード設定・ID はセットアップ時指定の場所を使い、private_key.pem と public_key.json を含み得ます。ピア受信箱と高度な CLI キューは指定 DB パスを使い、上記の既定場所とは限りません。

private_key.pem、ID ディレクトリ、キュー DB、未編集ログを公開しないでください。このガイドは提出を求めません。

## 私的なパスとファイル

作業領域は明示選択したローカルフォルダーです。通常のパスは OS パスであって所有権移譲ではありません。GUI の現在の作業領域はセッション状態で、このフローは最近使ったフォルダーの汎用同期サービスを提供しません。

ただし別の場所にパスが残る場合があります。preferences.json はノード設定を参照でき、協働／公開データは受信箱を参照できます。ログにもパスを含み得ます。作業領域のウィンドウを閉じても、全参照が消えるわけではありません。

既存のローカルファイルアダプターは指定テキストファイルを扱い、名前、シンボリックリンク／再解析ポイント、読み書き間の変更を確認します。保存は一時ファイルとアトミック置換、既存完全性確認を使います。汎用クラウドドライブではありません。

これらはローカル暗号化をしません。OS アカウントとディスクを保護し必要なバックアップを取ってください。SQLite コピー前にクライアントを終了します。稼働中 WAL DB を任意の単独ファイルとして扱ってはいけません。プログラム移動で作業領域、ID、状態が自動移動することもありません。

### プロバイダーやピアへ届く内容

ローカル AI は選択・承認入力を使用し、既存ジョブモデルは入力と指示をキューへ永続化できます。ピア開示は別途承認が必要です。入力に私的パス、秘密、個人情報を含めても、承認済み通信がそれを無害にはしません。

TLS は認証済みピア接続を保護しますが、端点 IP を各ネットワークから隠さず、侵害された端末の安全も保証しません。

## ブラウザーセッションと私的アクセス

ログインは既存 Web アプリと Internet Identity を使用します。ネイティブクライアントは II セッションを引き継ぎません。**Kontrollér forbindelse** は公開 API を匿名確認するだけで、成功しても私的記録やブラウザーセッションの有効性はわかりません。

ローカル検証済みブラウザー修正は、ログアウト／利用者変更時に私的キャッシュとフォームを消去し、期限切れを扱い、取得前に所有者と SHA-256 を確認します。バックエンド修正は匿名の私的アクセスと全体監査メタデータを制限します。これはローカルソフトウェアの証拠です。この先行版で配備したわけではなく、実稼働 II エンドツーエンドは未検証です。

Web の私的アクセス終了には既存のブラウザーログアウトを使います。デスクトップ終了や API プロファイル削除はログアウトでも単独での権限取消でもありません。既存の付与／取消は認可されたインターフェースを使い、この版は新しい権限種別を導入しません。

### ネイティブ私的ファイルアクセス

**Private II storage** は情報表示のみです。欠けている認可済みブラウザー／ネイティブファイル経路は未実装です。ノードが人の所有者として書くことは許されず、読み取り権を書き込み権へ解釈してはいけません。別の私的ストレージでこの境界を迂回しません。

### 私的結果と全体知識

ローカル提案とピア回答は、完成した検証済み知識ではありません。任意公開は検証、共有同意、役割、バックエンド受理に従います。完全性の一致だけでは品質承認も公開許可も得られません。

全体共有前に依頼者が権威ある検証済み結果を直接私的取得する機能は延期です。未実装の所有者チャネルからの取得を約束しません。

### エラーと漏えいの疑い

関連操作を止め、証拠を私的に保全して SECURITY.md に従います。秘密を除いた説明と版を提供し、鍵、セッション、私的 DB は提供しません。SHA-256 不一致はバイト差を意味します。ファイルやハッシュの欠落は別のエラーであり、改ざんの証明と呼んではいけません。

MCP は rc.2 後に別途判断・承認する機能であり、ここでは未実装です。この文書は本番環境や Internet Identity の新たな変更を意味しません。
