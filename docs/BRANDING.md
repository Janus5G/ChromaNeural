# ChromaNeural branding

The RC5 Windows Inno Setup definition uses `packaging/branding/ChromaNeural.ico`; its Start Menu shortcut uses the installed client icon. Linux retains its hicolor PNG/SVG and desktop entry. Native acceptance of each new package is separate from source inspection.

`docs/images/chroma-neural-hero.png` is version-neutral product artwork, not an application screenshot. The obsolete rc.1 social-preview artwork is excluded from RC5 release inputs and preserved only in local historical evidence. Actual RC5 documentation captures are listed in [the screenshot manifest](SCREENSHOT_MANIFEST.json) and [capture policy](SCREENSHOTS.md).

The withdrawn RC4 documentation screenshots and PDFs are not RC5 release inputs. Earlier icon/package evidence remains in the preserved RC4 baseline, not as a current RC5 acceptance claim.
