**rc.2 文档状态：** 本候选版本尚未公开发布。本地化与可扩展 i18n 已通过本地验证；rc.2 原生构建和软件包验收仍待完成。以下安装、平台、LAN/WAN、推理及线上服务证据，除明确标为 rc.2 外，均属于历史 rc.1 证据。rc.1 下载不包含 rc.2 本地化。

### 本地智能，明确授权的协作。

ChromaNeural 将本地 AI 工作、持久工作队列和已批准对等节点通信连接起来。由您决定处理哪些输入、共享哪些贡献。模型生成的回答不会因此自动变为正确或已验证。

本版支持的协作类型是代码提案，不是自动接收并执行任意远程任务的通用市场。桌面端尚无提交所有问题或研究类型的通用按钮。

![实际 Windows 客户端，参与已停止，未加载私人账户或数据。](../images/chroma-neural-overview.png)

### rc.2 语言支持

单一客户端提供 en、da、de、fr、ja、zh-CN、hi-IN。默认和回退均为英语。侧栏可切换应用文本并保存供下次启动使用。可扩展注册表支持新增目录，无需单独客户端或重复 GUI 逻辑。偏好和启动覆盖详情见用户指南。

### 目前可用

- 查看参与状态并保存资源偏好。
- 检查公开后端 API 是否响应。
- 使用现有本地 AI 为选定文件提出修改。
- 在支持的 Windows 配置中，通过后台进程处理已批准本地任务。
- 使用现有高级 CLI，执行经明确批准且关联原任务的对等协作。

## 从输入到结果

通用资源共享仍禁用。安装和连接成功不授予网络准入、不分配任务，也不发放 ChromaPoints。

### 1. 输入与许可

现有任务标识源输入、指令和所选提供者／模型。本地 AI 处理和联网各需相应批准。打开文件夹不等于允许共享。

### 2. 队列与处理

现有 SQLite 队列保留任务身份和状态。租约为工作进程保留任务。受控暂停、取消、停止和重启已在所述 Windows 配置内验证，不引入平行任务数据库。

### 3. 可选对等协作

问题和回复保持与原任务关联。ChromaSpeechAI 使用已批准节点身份及 TLS。接收内容保存在收件箱中并保持惰性：它是数据，不是执行代码的许可。公开源代码需要明确同意。

### 4. 完整性与审查

在现有流程提供的范围内，结果携带身份、哈希和来源信息，可区分本地与节点贡献。SHA-256 相同只说明字节相同，不评价技术质量。现有权威验证流程接受前，结果仍未验证。

### 5. 可选发布

全局共享使用现有发布流程，要求验证、同意、角色和后端接受。私人文件不会自动成为 Shared Network Knowledge。发布软件已本地验证，但本版不证明生产发布服务已经可用。

在可选全局共享之前，让请求者直接私下获取权威验证结果的功能已延期。这与读取本地、仍未验证的任务结果不同。

## 隐私与信任

### 三个独立区域

**您的计算机：** 工作文件、设置、队列、结果和日志。本地 AI 提供者在本机处理明确选择的输入。应用不会自动加密静态数据。

**您的浏览器：** 现有 Web 应用使用 Internet Identity，由实际已认证调用者决定所有者访问。复制的连接元数据不是登录会话。

**已批准节点与共享结果：** 相应授权控制发送内容。网络连接可能暴露 IP 地址和节点身份；ChromaNeural 不承诺匿名。

外部服务器处理提示词时，输入必须离开计算机。ChromaNeural 本地提供者可在本机处理所选输入。选择节点协作或浏览器存储仍跨越数据边界。差别在明确控制和隔离，而非承诺联网从不共享信息。

### 哪些已验证？

Windows 客户端与全新安装有自动检查和人工 GUI 验收。Windows、Linux amd64、macOS Intel 有原生构建／包检查。真实双机 LAN、移动网络到家庭网络的直接 WAN、真实本地模型推理均有记录。使用合成后端状态或身份的测试不是线上 Internet Identity 测试。

### 哪些尚未验证？

线上 Internet Identity 端到端、准入和迁移。macOS 人工 GUI 与 Linux DEB 完整安装／卸载生命周期也未验收。借助浏览器所有者权限的原生私人文件上传／下载尚未实现。专用硬件性能未经物理验证。

软件包未签名，macOS 未公证。Windows、Linux、macOS 是在这些预发布限制内的官方平台。

官方 Android 和 iOS 支持推迟至以后。

详见用户、隐私与存储、安装、已验证能力指南。

MCP 仍是 rc.2 之后需要单独决策和验收的功能，此处尚未实现。本文档不代表新增生产环境或 Internet Identity 变更。
