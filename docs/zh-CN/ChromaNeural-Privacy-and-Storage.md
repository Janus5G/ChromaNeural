## 三条数据边界

**本地客户端：** 工作文件、本地任务、设置与日志保存在您的计算机。由您选择工作区与操作；选择文件夹不自动上传。

**浏览器与 Internet Identity：** 私人 Web 访问使用现有应用和实际已认证调用者。JSON 中 Principal 是标识符，不是所有者权限证明。节点不得借用人的浏览器会话。

**节点与共享知识：** 经单独批准的内容可发送给已批准节点。全局发布有独立验证、同意、角色及后端要求。私人数据不会自动成为 Shared Network Knowledge。

隔离不改变 Internet Identity、Web 存储模型或既有所有权，也不代表静态加密或网络匿名。

### 与集中提示词处理比较

中央 AI 服务在外部服务器处理时，输入离开计算机。本地推理路径可在本机处理选择的输入。选择网络协作仍会发送已批准内容；Web 私人存储由现有所有者模型控制。

ChromaNeural 不声称其他 AI 都无隐私，也不声称本地存储本身就足够。操作系统、备份、提供者和批准内容仍很重要。

### 不隐式转移权限

API 配置含公开字段及可能的 Principal，不是登录令牌。节点有保存在指定本地路径的独立身份。注册不自动获得准入，资源偏好不授予私人对象访问。

## 数据位置

### 默认状态目录

Windows：
```
%LOCALAPPDATA%\ChromaNeural\client
```

Linux 与 macOS：
```
${XDG_STATE_HOME:-$HOME/.local/state}/chroma-neural/client
```

macOS 使用与 Linux 相同的 XDG／回退规则，不自动使用 Library/Application Support。显式 --state-dir 优先，否则可用 CHROMA_STATE_DIR。后续启动使用同一位置以继续原配置。

### 状态文件

- **preferences.json：** 主题、参与、CPU／线程／内存、空闲／电池及节点配置路径，无 II 会话。
- **ui-language.json (rc.2)：** 仅版本 1 和注册语言标识，GUI 明确选择时存于同一状态目录。无 II 会话，不改变 preferences.json。缺失／无效／过大／不支持时不破坏原件而回退英语。后续显式保存保全无效原件，失败保留当前语言。--language 不持久化。
- **api-connection-v1.json：** 保存的 API 配置。Principal 可识别人；公开元数据不是匿名数据。
- **work-queue.db：** 现有 SQLite 队列和关联发布状态，可含源文本、指令、结果和引用。运行时可创建 -wal、-shm。
- **balance-cache.json：** 先前获取的记账状态。缓存不产生权威积分奖励。
- **client.log：** 轮转日志，每文件至多 1 MiB、三个备份。回溯可含本地路径。

读取时保留无效设置／配置，后续明确保存可保留带日期备份。排障时不要自动删除。

### 其他明确位置

工作文件位于所选工作区。节点配置／身份使用设置时指定目录，可含 private_key.pem 和 public_key.json。节点收件箱与高级 CLI 队列使用明确数据库路径，不一定在默认目录。

绝不公开 private_key.pem、身份目录、队列数据库或未脱敏日志。本文不要求提供它们。

## 私人路径与文件

工作区是明确选择的本地文件夹。普通路径作为 OS 路径使用，不转移所有权。GUI 当前工作区属于会话状态，此流程不提供通用的最近文件夹同步服务。

路径仍可能保留在其他地方：preferences.json 可以引用节点配置，协作／发布数据可以引用收件箱，日志也可包含路径。因此关闭工作区窗口不表示所有路径引用都消失。

现有本地适配器处理命名文本文件，检查名称、符号链接／重解析点及读写间变化。保存使用临时文件、原子替换与现有完整性检查，不是通用云盘客户端。

这些机制不加密本地数据。保护 OS 账户和磁盘并按需备份。复制 SQLite 状态前退出；活动 WAL 数据库不能当成任意孤立文件。移动程序不会自动移动工作区、身份和状态。

### 提供者或节点收到什么？

本地 AI 使用已选且已批准输入。现有任务模型可把输入和指令持久存入队列。向节点披露另需批准。输入含私人路径、秘密或个人信息时，获批传输不会使内容无害。

TLS 保护已认证节点连接，不隐藏端点 IP 对各自网络的可见性，也不保证被入侵端点的安全。

## 浏览器会话与私人访问

登录使用现有 Web 应用和 Internet Identity，原生客户端不接管 II 会话。**Kontrollér forbindelse** 匿名检查公开 API，成功不说明私人记录可访问或浏览器会话有效。

本地验证的浏览器修正会在退出和切换用户时清理私人缓存／表单、处理过期、下载前验证所有者和 SHA-256。后端修正限制匿名私人访问及全局审计元数据。这是本地软件证据；本预发布没有部署这些修改，实际线上 II 端到端仍未验证。

使用现有浏览器流程退出私人 Web 访问。关闭桌面或忘记 API 配置不等于浏览器退出，也不会自行撤销授权。既有授权／撤销需走其授权接口；本版无新权限种类。

### 原生私人文件访问

**Private II storage** 仅为信息。缺失的授权浏览器／原生文件通道尚未实现。节点不能以人类所有者身份写入，也不能把读授权当写授权。没有替代私人存储绕过边界。

### 私人结果与全局知识

本地提案和节点回复不是完成验证的知识。可选发布需验证、共享同意、角色及后端接受。完整性相同不等于质量批准或发布许可。

请求者在可选全局共享前直接私人下载权威验证结果的功能延期，不承诺通过未实现所有者通道取回。

### 错误与疑似泄露

停止相关操作、私下保全证据并遵循 SECURITY.md。提供脱敏说明及版本，不提供密钥、会话和私人数据库。SHA-256 不同说明字节不同；文件或哈希缺失属于另一错误，不能称为已证实篡改。

MCP 仍是 rc.2 之后需要单独决策和验收的功能，此处尚未实现。本文档不代表新增生产环境或 Internet Identity 变更。
