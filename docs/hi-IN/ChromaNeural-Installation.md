## स्थापना

ChromaNeural 0.2.21-rc.2 दस्तावेज़ | अप्रकाशित उम्मीदवार | 3 अक्टूबर 2026

**rc.2 दस्तावेज़ की स्थिति:** यह उम्मीदवार सार्वजनिक रूप से जारी नहीं हुआ है। स्थानीयकरण और विस्तार योग्य i18n का स्थानीय सत्यापन सफल है; rc.2 के मूल प्लेटफ़ॉर्म बिल्ड और पैकेज की स्वीकृति बाकी है। नीचे स्थापना, प्लेटफ़ॉर्म, LAN/WAN, अनुमान और लाइव सेवा के प्रमाण पुराने rc.1 के हैं, जब तक स्पष्ट रूप से rc.2 न लिखा हो। rc.1 डाउनलोड में rc.2 का स्थानीयकरण नहीं है।

## पुराने rc.1 की स्थापना संदर्भ

अभी कोई सार्वजनिक rc.2 पैकेज नहीं। नीचे नाम और आदेश जानबूझकर rc.1 हैं; भाषा चयन या रजिस्ट्री नहीं लगाते। तैयार स्थानीय rc.2 में --language केवल उस लॉन्च की भाषा है; Windows -Language लेता है। GUI चयन सहेजता है। rc.1 का नाम न बदलें या अप्रमाणित rc.2 URL न लगाएँ।

### SHA-256 जाँच

डाउनलोड पैकेज की निर्देशिका में उचित आदेश चलाएँ।

Windows PowerShell:
```
Get-FileHash -Algorithm SHA256 -LiteralPath '.\ChromaNeural-0.2.21-rc.1-windows-x64.exe'
```

Linux:
```
sha256sum chromaneural_0.2.21.rc.1_amd64.deb
```

macOS:
```
shasum -a 256 ChromaNeural-0.2.21-rc.1-macos-x86_64.zip
```

SHA256SUMS.txt में ठीक उसी नाम की पूरी 64-अक्षर राशि मिलाएँ। अंतर पर रुकें। हैश बाइट अखंडता जाँचता है, स्वतंत्र प्रकाशक पहचान नहीं। पाँच प्रकाशित हैश docs/DOWNLOADS.md में भी हैं।

## Windows x64

### ज़रूरतें

Python 3.14, Tk, py/pyw लॉन्चर और Node.js 24 स्थापित करें। EXE प्रति-उपयोगकर्ता ऑफ़लाइन इंस्टॉलर है, पूरा जमे हुए Python/Node रनटाइम नहीं। अस्थायी खोलने और स्थापना के लिए करीब 2 GB खाली रखें।

### चरण

1. ऊपर बताए अनुसार EXE सत्यापित करें।
2. OS चेतावनी देखकर खोलें और पुष्टि करें।
3. प्रोग्राम इस संस्करण निर्देशिका में जाते हैं:
```
%LOCALAPPDATA%\Programs\ChromaNeural\0.2.21-rc.1
```
4. वहीं Start-ChromaNeural.ps1 चलाएँ:
```
& "$env:LOCALAPPDATA\Programs\ChromaNeural\0.2.21-rc.1\Start-ChromaNeural.ps1"
```
5. पहली बार संसाधन पसंद सहेजें। लॉगिन और कनेक्शन से वैकल्पिक सार्वजनिक API जाँचें।

लॉग %TEMP%\ChromaNeural-install.log है। मौजूद गंतव्य अस्वीकार होता है; स्वतः उसी जगह अपग्रेड नहीं। स्वतः भागीदारी या OS स्टार्टअप पंजीकरण नहीं। यह RC डेस्कटॉप शॉर्टकट स्वतः नहीं बनाता।

ICP SDK और लॉक निर्भरताएँ शामिल हैं। स्थापना के लिए npm ci न चलाएँ, NODE_PATH पुराने विकास वातावरण पर न रखें।

### हटाना और उपयोगकर्ता स्थिति

पूरा बंद करें। केवल संस्करण निर्देशिका हटाने से प्रोग्राम हटता है। %LOCALAPPDATA%\ChromaNeural\client की स्थिति, कार्यक्षेत्र और अलग पहचान निर्देशिकाएँ रखें या स्पष्ट निर्णय से अलग सँभालें। स्वचालित अनइंस्टॉलर नहीं है।

## Linux amd64

मूल परीक्षण Ubuntu 24.04 amd64 का है, हर वितरण/संस्करण का नहीं। WSL को मूल Linux पैकेज परीक्षण का विकल्प नहीं माना गया।

Python 3.11+, Tk, वितरण का cryptography, Node.js 20+, libgomp1 चाहिए। निर्भरताएँ वितरण पैकेज प्रबंधक से लें। डाउनलोड निर्देशिका में:
```
sudo apt install ./chromaneural_0.2.21.rc.1_amd64.deb
```

ऐप मेनू या इससे शुरू करें:
```
chromaneural
```

प्रोग्राम /opt/chromaneural, लॉन्चर /usr/bin/chromaneural, डेस्कटॉप विवरण /usr/share/applications/chromaneural.desktop में हैं। स्थापना बाद npm नेटवर्क डाउनलोड या उपयोगकर्ता स्थिति का स्वतः माइग्रेशन नहीं।

मूल बिल्ड, खोलना, अखंडता, SDK, CLI और Xvfb/Tk सत्यापित हैं। पूरा dpkg स्थापना/हटाना चक्र असत्यापित है। प्रकाशित desktop प्रविष्टि में उत्पाद-विशेष आइकन नहीं, पर लॉन्च होता है।

## macOS Intel x86_64

macOS 15+, काम करता Tk सहित Python 3.14, Node.js 24 चाहिए। निश्चित crypto निर्भरताएँ उसी Python में लगाएँ। स्वीकृत स्रोत स्नैपशॉट के मूल से:
```
python3 -m pip install --require-hashes -r packaging/requirements-runtime.txt
```

लॉक सेट cryptography 46.0.5, cffi 2.1.1, pycparser 3.0 है। ये रनटाइम ज़रूरतें हैं, II पहचान माँगना नहीं।

ZIP खोलें, ChromaNeural.app को Applications में रखें, मूल और चेतावनी देखकर खोलें। केवल Intel; Universal 2, Apple Silicon, Rosetta इस संस्करण के स्वीकृत प्रोफ़ाइल नहीं।

मूल बिल्ड, अखंडता, SDK, CLI, Tk सत्यापित; मैनुअल GUI असत्यापित। पैकेज अहस्ताक्षरित, गैर-नोटरीकृत और उत्पाद-विशेष बंडल आइकन रहित है। macOS में Qwen/llama.cpp नहीं। स्पष्ट स्थानीय Ollama को अलग स्थापित मॉडल चाहिए; नियंत्रित पृष्ठभूमि योगदान असमर्थित।

## पहली शुरुआत और आगे

![असली Windows संसाधन सेटिंग; विंडो सजावट प्लेटफ़ॉर्म अनुसार बदल सकती है।](../images/chroma-neural-resources.png)

चुनें और सहेजें। अवलोकन केवल पुष्टि मान दिखाता है; डैश कमाई का वादा नहीं। सामान्य साझाकरण बंद है। **Afslut ChromaNeural** से पूरा बंद करें।

शुरुआत विफल हो तो पहले ज़रूरतें, सही पैकेज और संरचना देखें। पुरानी स्थिति रखें; पहचान रीसेट या रिपोर्ट में निजी डेटा न डालें। उपयोगकर्ता और गोपनीयता मार्गदर्शिका देखें।

स्थापना Internet Identity, उत्पादन बैकएंड या ब्राउज़र सत्र नहीं बदलती। सार्वजनिक API पहुँच Windows पर सत्यापित थी। वास्तविक लाइव II पूर्ण प्रवाह, प्रवेश और माइग्रेशन असत्यापित हैं।

आधिकारिक Android और iOS समर्थन स्थगित है।

ऑनलाइन दस्तावेज़ अपरिवर्तनीय RC बाइनरी/स्रोत ZIP से नया हो सकता है। केवल दस्तावेज़/आइकन के लिए रिलीज़ फ़ाइल नहीं बदली जाती। आइकन स्थिति docs/BRANDING.md में है।

MCP, rc.2 के बाद अलग निर्णय और स्वीकृति वाला फीचर है; यहाँ लागू नहीं है। इस दस्तावेज़ का अर्थ उत्पादन या Internet Identity में कोई नया बदलाव नहीं है।
