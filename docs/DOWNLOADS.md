# ChromaNeural RC4 candidate files

0.2.21-rc.4 is being prepared locally. No public download is available.
Previous release files and their checksums must not be used for RC4.

Expected formats: Windows x64 EXE, Linux amd64 DEB,
source ZIP and SHA256SUMS.txt. Availability and acceptance remain pending;
see [current status](../RELEASE_NOTES.md).

Compare the complete filename and SHA-256 against the accepted candidate's
SHA256SUMS.txt. Hashes prove byte integrity, not publisher identity.
See [installation](../INSTALLATION.md) for prerequisites and unsigned-package limits.
