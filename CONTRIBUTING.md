# Contributing

Keep changes narrow, additive and backward compatible. Preserve data formats, identity/owner semantics, queue leases/retries, provider routing, inert peer payloads, verification and publication requirements. Include targeted tests and classify mock/local/native/physical evidence honestly. Do not add credentials or user data.

Use native runners for package verification. No deployment or public release is performed by the included workflow. Community ports are welcome through reviewed platform-specific adapters; the source must not be artificially limited to desktop. Do not remove fail-closed security boundaries to make a platform appear supported.

New ChromaNeural contributions use Apache-2.0 unless explicitly identified otherwise. Existing third-party/restricted components retain their licenses; a contribution does not relicense them.
