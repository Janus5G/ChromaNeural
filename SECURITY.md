# Security

REMOTE_EXECUTION=DISABLED. Received peer content remains inert. Local jobs require explicit approval. The node does not borrow a person's Internet Identity session. Private data is not automatically published. Owner authorization, peer approval, verification and publication consent remain separate boundaries. Downloading does not award ChromaPoints.

Do not post private keys, seed phrases, tokens, personal records or raw user-state logs in issues. Report vulnerabilities privately using the repository's GitHub private vulnerability reporting when enabled; if unavailable, request a private contact without disclosing exploit details publicly. No unverified security email is advertised.

This RC has local security evidence, not certification or a claim that every platform/live deployment has been audited. The external Internet Identity component is unchanged. See VERIFICATION.md and KNOWN_LIMITATIONS.md.
